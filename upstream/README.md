# Contributions to Hermes Agent and Fetch.ai

Ready-to-post contributions to the two projects this one builds on. Each goes out from the repository owner's own GitHub, Discord, or X account. None of them claims an affiliation: they are a community project's offers to the teams behind Hermes Agent and Fetch.ai, and each team decides what to take.

| What | Where it goes | When | Files |
|------|---------------|------|-------|
| List the plugin in Hermes' plugin catalog | A pull request to [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent) adding one catalog entry | After merging here, bumping the version, and pushing its tag | [`hermes-pr/`](hermes-pr/SUBMIT.md) |
| Ask Hermes for a public "ask the user to confirm" plugin API | An issue on [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent/issues), feature request template | Any time; the catalog PR mentions it | [`hermes-issue/plugin-confirm-api.md`](hermes-issue/plugin-confirm-api.md) |
| Fix the payment checks in Fetch.ai's FET payment example | A pull request to [fetchai/innovation-lab-examples](https://github.com/fetchai/innovation-lab-examples) | Any time | [`fetch-examples/fet-example-payment-checks/`](fetch-examples/fet-example-payment-checks/README.md) |
| Introduce the project to Fetch.ai's developers and ask what ASI:One's payment card does | A post in Fetch.ai's Discord | After the example PR is open | [`fetch-community/introduction.md`](fetch-community/introduction.md) |

Later, once a real ASI:One purchase has worked: a small example agent for the `contributors/` folder of Fetch.ai's examples, which their [contribution guide](https://github.com/fetchai/innovation-lab-examples/blob/main/contributors/README.md) welcomes. It needs a demo screenshot from that purchase.

Before posting anything, re-check it against the target's current code and rules: both projects move quickly. Never paste a seed, an API key, or a personal email address into any of them. Commit to other repositories with your GitHub noreply address, as [`hermes-pr/SUBMIT.md`](hermes-pr/SUBMIT.md) shows.
